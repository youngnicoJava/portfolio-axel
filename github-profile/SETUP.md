# Publicar el perfil

1. En GitHub, crear un repositorio **público** llamado exactamente `youngnicoJava`.
2. Subir `README.md` y la carpeta `assets` de este directorio a la raíz del nuevo repositorio. No subir la carpeta contenedora `github-profile` ni este archivo de instrucciones. La fila de iconos utiliza los SVG de `assets`; los badges de proyectos se sirven desde Shields.io.
3. Confirmar los cambios en la rama principal. El README aparecerá automáticamente en el perfil.

El archivo de perfil está en español e incluye un resumen desplegable en inglés. Los proyectos utilizan badges pequeños de fondo gris carbón uniforme con estilo `flat` y color solo en los logos, con tonos claros para conservar contraste. Kafka mantiene su logo claro porque su identidad original es monocromática. Sus URLs están al final del README para facilitar cambios: el color de fondo es `252A34` y `logoColor` controla cada icono. Tecnologías conserva una fila de iconos locales de 32 px y una tabla de texto plano. Su licencia se conserva en `assets/LICENSE.txt`.

Reemplazar `Portfolio: enlace por agregar` por `[Portfolio](https://tu-dominio)` cuando exista una URL pública.

Bio breve sugerida para el campo Bio de GitHub:

> Software Developer | Java · Kotlin · Spring Boot · Quarkus · Angular | Buenos Aires, Argentina

Repositorios para fijar en el perfil: `fixy-readme`, `loan-approval-engine`, `credit-risk-engine` y `fraud-detection-engine`.
